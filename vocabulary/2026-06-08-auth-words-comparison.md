## 1. Authentic

### Pronunciation
- /ɔːˈθen.tɪk/

### Meaning
**Adjective** - Real, genuine, not fake; true to origin.

### Usage in Daily Life
- "This is an authentic Italian restaurant." (正宗意大利餐厅)
- "Is this authentic designer bag?" (真的名牌包吗)
- "That's his authentic smile." (真诚的微笑)

### Usage in Tech
- "We need an authentic user experience." (真实的用户体验)
- "This is the authentic data from the server." (真实的服务器数据)

### Example Sentences
> "I can confirm this is an authentic document, not a forgery."

> "The restaurant serves authentic Sichuan cuisine."

---

## 2. Authenticity

### Pronunciation
- /ˌɔː.θenˈtɪs.ə.ti/

### Meaning
**Noun** - The quality of being genuine or real; trustworthiness.

### Usage
- "The authenticity of the painting was verified."
- "We need to check the authenticity of the user."
- "Social media influencers care about authenticity."

### Example Sentences
> "The authenticity of this signed Michael Jordan jersey is questionable."

> "In the age of fake news, authenticity matters more than ever."

> "Users value authenticity over perfection on social media."

---

## 3. Authentication

### Pronunciation
- /ˌɔː.θen.tɪˈkeɪ.ʃən/

### Meaning
**Noun** - The process of verifying WHO you are (identity).

### The Key Question: "Are you really who you claim to be?"

### Common Authentication Methods
| Method | Example |
|--------|---------|
| Password | Username + Password |
| Biometrics | Fingerprint, Face ID |
| 2FA | Text message code + Password |
| SSO | Single Sign-On (Google/Apple login) |

### Usage in Tech
- "Two-factor authentication (2FA) is essential."
- "Authentication failed. Please try again."
- "The system uses OAuth for authentication."

### Example Sentences
> "Authentication is the first step in security - proving your identity."

> "We use multi-factor authentication to verify user identity."

> "Authentication failure: wrong password."

---

## 4. Authorization

### Pronunciation
- /ˌɔː.θər.ɪˈzeɪ.ʃən/

### Meaning
**Noun** - The process of granting WHAT you are allowed to do (permissions).

### The Key Question: "Are you allowed to do this?"

### Common Authorization Levels
| Level | Example |
|-------|---------|
| Admin | Full access to all features |
| Editor | Can edit but not delete |
| Viewer | Read-only access |
| Guest | Limited basic access |

### Usage in Tech
- "Admin authorization required."
- "Your account doesn't have authorization for this action."
- "Role-based authorization controls access levels."

### Example Sentences
> "Authorization determines what resources a user can access."

> "Even if you're authenticated, you still need authorization to view sensitive data."

> "The authorization check failed. You don't have admin privileges."

---

## Side-by-Side Comparison

| Aspect | Authentication | Authorization |
|--------|---------------|---------------|
| **Question** | "Who are you?" | "What can you do?" |
| **Process** | Verify identity | Grant permissions |
| **Analogy** | Showing your ID at the door | Room key you're given |
| **Order** | Happens FIRST | Happens AFTER authentication |
| **Example** | Login with password | Access to admin panel |
| **Abbreviation** | Often "auth" (narrow) | Often "authz" (tech) |

---

## The Flow: Authentication → Authorization

```
1. USER LOGS IN
   ↓
2. AUTHENTICATION (Who are you?)
   - Verify password, 2FA, biometrics
   - Result: "Yes, this is John"
   ↓
3. AUTHORIZATION (What can you do?)
   - Check permissions, roles
   - Result: "John is a regular user"
   ↓
4. ACCESS GRANTED
   - John can view and edit his own data
   - John CANNOT access admin panel
```

## Real-World Analogy

### Airport Security
- **Authentication**: Showing your passport and ticket at check-in
  - "Are you really who your ticket says you are?"

- **Authorization**: Going through security and immigration
  - "Are you allowed to enter this country?"

- **What you can do**: Boarding your specific flight
  - "You can go to Gate 12, but not the pilot's cabin"
