## 1. Alternative

### Pronunciation
- /ɔːlˈtɜːr.nə.tɪv/ (noun) / /ɒlˈtɜː.nə.tɪv/ (adjective)

### Meaning
**Noun** - One of two or more available possibilities; a different option.
**Adjective** - (Of one or more things) available as another possibility.

### Usage in Tech
- "There's an easier alternative: do it through the admin UI instead."
- "What's the alternative approach?"
- "Switch to the alternative implementation."
- "We need to consider alternative solutions."

### Common Collocations
- **alternative to** something — "This is a cheaper alternative to Redis."
- **alternative approach / method / solution** — 替代方案
- **viable alternative** — 可行的替代方案
- **no alternative but to** — 别无选择只能...

### Example Sentences
> "Easier alternative: do it through the admin UI instead, and make sure the user has that role."

> "If the primary database fails, we have an alternative read replica."

> "Is there any alternative to using a message queue for this use case?"

> "We explored several alternatives before settling on Kafka."

### Personal Note
"Alternative" implies a choice between options. Don't confuse with "alternate" (交替的、轮流的). In tech conversations, "alternative" is extremely common when discussing design choices and trade-offs.

## 2. Grant

### Pronunciation
- /ɡrænt/ (verb & noun)

### Meaning
**Verb** - To give, bestow, or confer (a right, permission, privilege).
**Noun** - A sum of money or other payment given for a particular purpose; a formal bestowal of rights.

### Usage in Tech (Most Common: Authorization/Permissions)
- "This grants full permissions to every user holding it."
- "Grant admin access to the new team member."
- "The system grants read-only access by default."
- "You need to grant permission for the app to access your location."

### Common Collocations
- **grant access / permission** — 授予访问权限
- **grant a role** — 授予角色
- **grant privileges** — 授予特权
- **take for granted** — 视为理所当然（⚠️ 非常常见的日常表达）
- **grant authorization** — 授予授权

### Example Sentences
> "This role grants full permissions to every user holding it."

> "The OAuth flow grants the application limited access to the user's data."

> "Don't grant admin privileges unless absolutely necessary."

> "We need to grant the CI pipeline access to the private registry."

### Daily Life Usage
> "Don't take your health for granted." — 不要把健康视为理所当然。

> "I took it for granted that he would help." — 我以为他会帮忙是理所当然的。

### Personal Note
In tech, "grant" is almost always about permissions/authorization. The phrase "take something for granted" is one of the most useful English expressions — master it!

## 3. Code Review

### Pronunciation
- /koʊd rɪˈvjuː/

### Meaning
**Noun Phrase** - A systematic examination of source code by one or more developers, intended to find bugs, improve code quality, ensure adherence to coding standards, and share knowledge.

### Definition
> "A code review is when one or more developers examine someone else's code to catch bugs, ensure quality, and share knowledge before the code is merged into the main branch."

### Key Concepts

| Aspect | Description |
|--------|-------------|
| **Purpose** | Catch bugs, improve quality, share knowledge |
| **Who** | Peers, senior developers, team leads |
| **When** | Before merging (typically via Pull Request) |
| **How** | Line-by-line review, comment, approve/request changes |
| **Tool** | GitHub PR, GitLab MR, Gerrit, Phabricator |

### Common Phrases
- "Submit a code review" / "Request a code review" — 发起代码审查
- "Pass code review" — 通过代码审查
- "Code review comments" — 审查意见
- "Blocking code review" — 阻塞性审查（必须修改才能合入）
- "Peer code review" — 同行代码审查

### Example Sentences
> "A code review is when one or more developers examine someone else's code to catch bugs, ensure coding standards, and share knowledge."

> "I submitted a pull request for code review. Can you take a look?"

> "The code review caught a critical security vulnerability before it went to production."

> "Our team requires at least two approvals before merging any code review."

> "Code reviews are not just about finding bugs — they're also a great way to learn from each other."

### Personal Note
Code review is a cornerstone of software engineering culture. The verb forms: "to review code" / "to do a code review". Don't say "review code" when you mean "code review" as a noun — they're slightly different registers.

## 4. Scaffold

### Pronunciation
- /ˈskæf.əld/

### Meaning
**Verb** - To generate a project structure or boilerplate code from a template or framework, providing a quick starting point for development.
**Noun** - A temporary structure used to support workers and materials (literal meaning in construction).

### Usage in Tech (Framework/CLI Context)
- "Scaffolded from the unibest framework."
- "Scaffold a new project with `npm create vite`."
- "The CLI scaffolds the entire project structure in seconds."
- "You can scaffold a new microservice using the template."

### Common Collocations
- **scaffold a project** — 快速生成项目
- **scaffolded from** — 基于...框架生成
- **scaffolding tool** — 脚手架工具
- **project scaffolding** — 项目脚手架、项目模板生成

### Example Sentences
> "The project was scaffolded from the unibest framework."

> "Run `npx create-react-app` to scaffold a new React application."

> "Most modern frameworks provide CLI tools to scaffold new projects quickly."

> "The scaffolding includes sensible defaults like ESLint, Prettier, and a testing setup."

### Literal Meaning (Construction)
> "The workers climbed the scaffold to reach the top floor."

### Personal Note
The tech usage is a metaphor from construction: just as scaffolding provides a temporary framework to build a building, code scaffolding provides a starter structure to build an application. Very common in framework documentation ("scaffold a new app", "scaffolding templates").
