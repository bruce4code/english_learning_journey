## Infinity vs Infinite

### Infinity (noun) - 无穷 / 无限
- Used as a noun or with "of"
- Example: "infinity of possibilities"

### Infinite (adjective) - 无限的 / 无穷的
- Used to modify nouns directly
- Example: "infinite possibilities"

---

## Programming Usage

**JavaScript Infinity:**
- `Infinity` is a global property representing mathematical infinity
- Example: `console.log(Infinity > 999999999)` // true
- Used in mathematical operations: `10 / 0` // Infinity

**Python:**
- `float('inf')` represents positive infinity
- Useful for initialization: `min_val = float('inf')`
