## Corrected Sentence

**Original**: "This issue occurs during loading embeding model phase?"

**Corrected**: "This issue occurs during the embedding model loading phase."

**Why the corrections?**:
1. **"embeding" → "embedding"** - correct spelling (double 'd')
2. **"loading embedding model phase" → "embedding model loading phase"** - more natural word order
3. **Added "the"** - article before "embedding model loading phase"

---

## Better Variations

**1. This issue occurs while loading the embedding model.**
- More concise and natural
- "while loading" vs "during [phase]"
- Good for bug reports

**2. The problem happens during the embedding model loading phase.**
- "The problem" instead of "This issue"
- "happens" instead of "occurs"
- More conversational tone

**3. We observe this error when loading the embedding model.**
- "We observe" adds context (who is seeing the issue)
- "this error" more specific than "this issue"

**4. The error arises during the initialization phase of the embedding model.**
- "arises" is a good alternative to "occurs/happens"
- "initialization phase" is precise

## Common Issue Report Sentences

### Describing When the Issue Occurs

- **"This issue occurs on startup."**
- **"The error happens during login."**
- **"The bug appears when submitting the form."**
- **"We see this behavior while processing large files."**
- **"This problem arises after updating to v2.0."**
- **"The crash occurs under heavy load."**
- **"It happens intermittently on mobile devices."**

### Describing Phases

- **initialization phase**
- **loading phase**
- **execution phase**
- **shutdown phase**
- **deployment phase**
- **testing phase**
- **development phase**
- **maintenance phase**

## Issue Report Template (English)

```markdown
## Issue: [Brief description]

**When does it happen?**
This issue occurs during the [phase] phase.

**Steps to Reproduce:**
1. [Step 1]
2. [Step 2]
3. [Step 3]

**Expected Behavior:**
[What should happen]

**Actual Behavior:**
[What actually happens]

**Environment:**
- OS: [Windows/Mac/Linux]
- Version: [x.y.z]
- Browser/Device: [Chrome/Safari/iOS/Android]

**Severity:** [P0/P1/P2/P3]
**Priority:** [Critical/High/Medium/Low]
```

## Triage Process

**In meetings, you might hear:**

- "Let's triage this week's new issues."
- "This bug needs to be prioritized as P1."
- "Who has context on this issue?"
- "Does this block the release?"
- "Can we reproduce this?"

**Asking for triage help:**
- "Could you help me triage this issue?"
- "What priority should we assign this?"
- "Is this blocking any work?"

## Technical Phrases for Debugging

- **"The issue is intermittent."** - 偶发问题
- **"It only reproduces on X."** - 仅在 X 上复现
- **"The error happens 50% of the time."** - 50% 概率出现
- **"We need to add more logging."** - 需要加日志
- **"Can you provide reproduction steps?"** - 能提供复现步骤吗？
- **"This is a regression from v1.9."** - 这是 v1.9 引入的回归问题
- **"The bug occurs under load."** - 负载下出现的 bug
