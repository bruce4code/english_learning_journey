## Words

### 1. idempotent
- **Pronunciation**: /ˌaɪ.demˈpə.tənt/
- **Part of Speech**: Adjective
- **Chinese Meaning**: 幂等的
- **Tech Context**: An API endpoint or operation is idempotent when calling it multiple times produces the same result as calling it once. This is a critical property for safe retries and reliable distributed systems.
- **Example Usage**:
  ```
  GET /api/users/123     // Idempotent - same response every time
  DELETE /api/users/123  // Idempotent - deleting same user twice = same outcome
  POST /api/users        // NOT idempotent - creates new user each time
  ```
- **Real-world Example**:
  ```javascript
  // Idempotent operation
  async function deleteUser(userId) {
    await api.delete(`/users/${userId}`);
    // Even if called 3 times, user is deleted only once
  }

  // Non-idempotent operation
  async function createUser(userData) {
    const user = await api.post('/users', userData);
    // Called 3 times = 3 new users created!
  }
  ```
- **Key Points**:
  - **Idempotent HTTP Methods**: GET, PUT, DELETE, HEAD, OPTIONS
  - **Non-Idempotent**: POST, PATCH (usually)
  - **Why it matters**: Network failures happen, clients retry → idempotent APIs handle this safely
- **Related Terms**:
  - safe (adj) - 安全的（不会修改资源）
  - retry-safe - 可重试的
  - distributed system - 分布式系统
  - reliable - 可靠的
- **Synonyms**: repeatable, reproducible
- **Personal Note**: Remember: "idem" = same, "potent" = powerful/effective → same result every time!
