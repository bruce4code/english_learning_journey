## Key Terms Breakdown

### 1. Fast (快速的)
- **Pronunciation**: /fɑːst/
- **Meaning**: High performance; handles requests with low latency
- **In Context**: "Express is fast because of its lightweight design."

### 2. Unopinionated (非固执的 / 灵活的)
- **Pronunciation**: /ˌʌn.əˈpɪn.jə.neɪ.tɪd/
- **Meaning**: The framework doesn't enforce a specific structure; you're free to organize your code however you want
- **Opposite**: **Opinionated** - a framework that tells you how to structure your project (e.g., Next.js, Ruby on Rails)
- **In Context**: "Express is unopinionated, so you can structure your app however you see fit."
- **Example**:
  - **Opinionated frameworks**: "Where should I put my files? The framework tells me."
  - **Unopinionated frameworks**: "Where should I put my files? Up to me!"

### 3. Minimalist (极简的)
- **Pronunciation**: /ˈmɪn.ɪ.məl.ɪst/
- **Meaning**: Very basic, minimal features included; you add what you need
- **In Context**: "Express is minimalist - it only includes the essentials."
- **Analogy**: "Express is like a basic kitchen knife - one tool that does one job really well."

### 4. Web Framework (Web 框架)
- **Pronunciation**: /web ˈfreɪm.wɜːk/
- **Meaning**: A set of tools and libraries for building web applications
- **In Context**: "Express.js is the most popular web framework for Node.js."

### 5. Node.js (/nəʊd dʒeɪ ɛs/)
- **Pronunciation**: /nəʊd dʒeɪ ɛs/
- **Meaning**: JavaScript runtime for server-side programming
- **In Context**: "Express.js runs on top of Node.js."

## Memory Tricks

- **Unopinionated**: Think "un-" (not) + "opinionated" (has strong opinions). Express doesn't have strong opinions about your code structure.
- **Fast**: Think "no magic" - simple architecture = fast execution
- **Minimalist**: Think "bare minimum" - just the essentials, no bloat
