## Core Terms

### 1. Agent
- **Pronunciation**: /ˈeɪ.dʒənt/
- **Chinese Meaning**: 智能体
- **Definition**: An AI system that can autonomously perceive environment, make decisions, and take actions to achieve goals.
- **Key Usage**: 
  - "An agent is an AI system that uses an LLM to determine which actions to take."
  - "Agents can use tools and interact with external systems."

### 2. Agentic AI / Agentic
- **Pronunciation**: /eɪˈdʒen.tɪk aɪ/
- **Chinese Meaning**: 智能体AI
- **Definition**: AI systems that can autonomously plan, reason, and execute multi-step tasks.
- **Key Usage**: 
  - "Agentic AI goes beyond simple text generation."
  - "Agentic AI systems can use tools and take actions."

### 3. LLM (Large Language Model)
- **Chinese Meaning**: 大语言模型
- **Definition**: A neural network trained on vast amounts of text data.
- **Key Usage**: 
  - "GPT-4, Claude, and Gemini are all LLMs."
  - "LLMs are the foundation of modern AI agents."

### 4. Tool Use
- **Chinese Meaning**: 工具使用
- **Definition**: The ability of AI to interact with external tools and APIs.
- **Key Usage**: 
  - "Tool use allows agents to search the web, run code, and access databases."
  - "Agents can call functions and execute code."

### 5. Reflexion
- **Chinese Meaning**: 反思模式
- **Definition**: A design pattern where the agent critiques its own output to improve quality.
- **Key Usage**: 
  - "Reflexion helps agents identify and correct their own mistakes."
  - "The agent generates output, then reviews it for errors."

## Agent Design Patterns

### 1. Reflection Pattern
- **Chinese Meaning**: 反思模式
- **Definition**: Agent reviews its own output and identifies areas for improvement.
- **Process**: Generate → Review → Revise → Output
- **Example**: Code generation agent reviews its own code for bugs.

### 2. Tool Use Pattern
- **Chinese Meaning**: 工具使用模式
- **Definition**: Agent uses external tools to complete tasks.
- **Tools**: Web search, API calls, code execution, database queries
- **Example**: Agent searches the web to answer a question.

### 3. Planning Pattern
- **Chinese Meaning**: 规划模式
- **Definition**: Agent breaks down complex tasks into smaller steps.
- **Process**: Analyze → Plan → Execute → Monitor
- **Example**: Agent creates a multi-step research plan.

### 4. Multi-Agent Pattern
- **Chinese Meaning**: 多智能体模式
- **Definition**: Multiple agents work together, each with specialized roles.
- **Communication**: Agents share information and coordinate tasks.
- **Example**: One agent writes code, another reviews it.

## Key Concepts

### 1. Autonomy
- **Pronunciation**: /ɔːˈtɒn.ə.mi/
- **Chinese Meaning**: 自主性
- **Definition**: The degree to which an agent can operate independently.
- **Levels**: 
  - Level 0: No autonomy (basic text generation)
  - Level 1: Simple task completion
  - Level 2: Multi-step reasoning
  - Level 3: High autonomy with tool use

### 2. Task Decomposition
- **Chinese Meaning**: 任务分解
- **Definition**: Breaking complex tasks into smaller, manageable subtasks.
- **Example**: "Write a report" → Research → Outline → Draft → Revise

### 3. Eval / Evaluation
- **Pronunciation**: /ɪˈvæl/
- **Chinese Meaning**: 评估
- **Definition**: Measuring the performance of AI systems.
- **Key Usage**: 
  - "Evals are crucial for building reliable agents."
  - "We use evals to measure accuracy and quality."

### 4. Error Analysis
- **Chinese Meaning**: 误差分析
- **Definition**: Identifying and categorizing errors to improve the system.
- **Process**: Identify error → Categorize → Prioritize → Fix

### 5. Orchestration
- **Pronunciation**: /ˌɔːrkɪˈstreɪʃən/
- **Chinese Meaning**: 编排
- **Definition**: Coordinating multiple agents or components.
- **Example**: "Orchestrating a team of specialized agents."

## Tools & Technologies

### 1. MCP (Model Context Protocol)
- **Chinese Meaning**: 模型上下文协议
- **Definition**: A protocol for connecting AI models to external data sources and tools.
- **Purpose**: Standardizes how agents access tools and data.

### 2. Code Execution
- **Chinese Meaning**: 代码执行
- **Definition**: Running code generated by the agent.
- **Use Cases**: Data analysis, calculations, automation.

### 3. API (Application Programming Interface)
- **Chinese Meaning**: 应用程序接口
- **Definition**: A set of rules for software communication.
- **Use Cases**: Integrating with external services.

### 4. RAG (Retrieval-Augmented Generation)
- **Chinese Meaning**: 检索增强生成
- **Definition**: Combining knowledge retrieval with text generation.
- **Use Cases**: Answering questions with specific knowledge.

## Advantages of Agentic AI

| Advantage | Description |
|-----------|-------------|

| **Tool Use** | Can interact with external systems and data |
| **Planning** | Can break down and execute complex tasks |
| **Iteration** | Can review and improve its own output |
| **Scalability** | Can handle multiple concurrent tasks |
