# Irregular Verbs: Memory Hacks

## Date
2026-05-10

## Topic
How to Memorize Irregular Verbs EASILY

---

## 🎯 The Secret: It's NOT About Memorizing!

**Truth**: You don't need to memorize all 3 forms separately!

**Strategy**: 
1. Learn the **PAST TENSE** (过去式) first
2. Learn the **PATTERN** that connects past → past participle
3. Use **STORIES** and **SOUNDS** to remember

---

## Hack 1: The "Same Sound" Trick

### A. Verbs ending in -T (过去式和过去分词相同)

**Pattern**: -T ending sounds in past = same past participle

| Base | Past | PP | Why? |
|------|------|-----|-------|
| sleep | **slept** | slept | Both END in **-ept** |
| keep | **kept** | kept | Both END in **-ept** |
| feel | **felt** | felt | Both END in **-elt** |
| deal | **dealt** | dealt | Both END in **-ealt** |
| mean | **meant** | meant | Both END in **-eant** |

### 💡 Memory Trick
> If past tense ends in **-ept, -elt, -ant, -ought** → Past Participle is the SAME!

## Hack 2: The "O-OW-OWN" Pattern

### Verbs with O → EW → OWN

| Base | Past | PP | Sound Pattern |
|------|------|-----|---------------|
| blow | blew | **blown** | O → EW → OWN |
| throw | threw | **thrown** | O → EW → OWN |
| grow | grew | **grown** | O → EW → OWN |
| know | knew | **known** | O → EW → OWN |
| draw | drew | **drawn** | AW → EW → AWN |
| fly | flew | **flown** | Y → EW → OWN |

### 💡 Memory Trick
> **"BLOW, THROW, GROW, KNOW"** → Just add **"ew"** in past, **"own"** in PP  
> **"O"** friends: **B**low, **TH**row, **KN**ow, **GR**ow, **DR**aw, **FL**y

## Hack 3: The "Ring-Sing-Swing" Pattern

### Verbs with -ing in the middle

| Base | Past | PP | Pattern |
|------|------|-----|---------|
| sing | sang | sung | ING → ANG → UNG |
| ring | rang | rung | ING → ANG → UNG |
| sink | sank | sunk | INK → ANK → UNK |
| drink | drank | drunk | INK → ANK → UNK |
| swim | swam | swum | IM → AM → UM |
| begin | began | begun | IN → AN → UN |

### 💡 Memory Trick
> **"I → A → U"** - Like the sounds cats make!  
> **Meow**: MEOW → MEOW → MEOW... wait, wrong animal!  
> Think: **SING → SANG → SUNG** (like ringing a bell)

## Hack 4: The "A-Back-EN" Pattern

### Verbs with A → B → EN

| Base | Past | PP | Pattern |
|------|------|-----|---------|
| break | broke | **broken** | A → O → EN |
| speak | spoke | **spoken** | EA → O → OEN |
| wake | woke | **woken** | AKE → OKE → OKEN |
| choose | chose | **chosen** | OOSE → OSE → OSEN |
| steal | stole | **stolen** | EA → O → OLEN |
| freeze | froze | **frozen** | EE → O → OZEN |

### 💡 Memory Trick
> **"Break-Broke-Broken"** → Picture a **broken** glass  
> **"Choose-Chose-Chosen"** → Think of being **chosen** for a team

## Hack 5: The "Tell-Sell-Think" Trick

### Irregular patterns to memorize as GROUPS

| Group | Verbs | Pattern |
|-------|-------|---------|
| **The -T Team** | sleep-slept, keep-kept, feel-felt | All end in -pt/-lt |
| **The -GHT Team** | bought, brought, thought, fought, caught, taught | All rhyme with "t" |
| **The O-OW-OWN Team** | blow-blew-blown, throw-threw-thrown, grow-grew-grown | O → EW → OWN |
| **The ING-ANG-UNG Team** | sing-sang-sung, ring-rang-rung, sink-sank-sunk | ING → ANG → UNG |

## Hack 6: The "Story" Method

### Create silly sentences with all 3 forms:

1. **"I **saw** the bird **fly**. It **flew** away and has **flown** to the sun."**

2. **"I **drank** water, I **drank** juice, and I have **drunk** too much!"**

3. **"I **wrote** a letter, I **wrote** an email, and I have **written** a book!"**

4. **"I **ate** an apple, I **ate** a banana, and I have **eaten** everything!"**

### 💡 How to Use
- Make up your OWN story with verbs you struggle with
- Say it out loud 3 times
- The sillier, the more memorable!

## Hack 7: The "Verb Card" Method

### Create flashcards with only 2 columns:

```
┌─────────────────┐
│     SPEAK       │  ← Just look at this
└─────────────────┘
         ↓
┌─────────────────┐
│     SPEAK       │
│     spoke       │  ← Try to recall
│     spoken      │
└─────────────────┘
```

### Step by Step:
1. Cover the bottom 2 rows
2. Say the past and past participle OUT LOUD
3. Check your answer
4. If wrong, say the correct answer 3 times

## Hack 8: The "Location" Memory

### Link each verb to a location:

| Verb | Location | Why? |
|------|----------|-------|
| SWIM | Pool | You swim in a pool |
| RIDE | Bike | You ride a bike |
| DRIVE | Car | You drive a car |
| FLY | Plane | You fly in a plane |
| WRITE | Pen | You write with a pen |
| READ | Book | You read books |

### 💡 Memory Trick
> Think: "Where do I USE this verb?" → The action happens THERE
